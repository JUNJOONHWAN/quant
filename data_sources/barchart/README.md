# Barchart Data Source

Canonical home for Barchart Premier access contracts used by quant workflows.

Keep here:
- symbol page and dashboard URL/page contracts
- options, IV, Greeks, gamma, max pain, put/call, time-and-sales fields
- CDP/browser extraction rules and failure recovery
- page-load validation, login checks, and source-status requirements

Do not store account secrets or raw one-off browser dumps here.
